页面默认启用：**`yongshang-video-loop.mp3`**（来自演示视频音轨）。

| 项目 | 说明 |
| --- | --- |
| 曲名 | 甬上四季 · 视频原声循环 |
| 文件 | `yongshang-video-loop.mp3`（27.9 秒，立体声，160 kbps MP3） |
| 来源 | 抽取自本仓库根目录 `指尖绽放.mp4` 的音轨（AAC → MP3），已裁掉片头静音并做 1.5 秒交叉淡化，作为无缝循环 |
| 作者/版权 | 原视频音轨版权归属其原作者（本项目未取得书面授权） |
| 用途 | **仅供课堂内部录屏展示**，不作为商用音频素材 |
| 是否需要署名 | 若视频原作者要求署名，按其要求处理 |

## 循环点

- 截取原音轨 `1.5s → 30.9s`（共 29.4s）作为循环段；
- 用 `acrossfade=1.5s` 将尾 1.5s 与首 1.5s 交叉淡化，使首尾在浏览器循环时听不出接缝；
- 输出时长 27.9s（循环段 29.4s − 尾首重叠 1.5s）。

## 公开发布风险提示

该音轨提取自项目演示视频，**未获得原作者的商用/公开发布授权**。若把含此音轨的录屏发布到 B 站、抖音、YouTube、小红书等视频平台，**可能被平台的内容识别（Content ID）系统判为版权侵权**，出现静音、限流、下架或索赔等风险。如需公开发布，请：
1. 改用目录中的程序合成版本（见下方「备选」），或
2. 联系原视频作者取得书面授权后再发布。

## 使用说明

- 全程只有一条循环背景音乐，不随季节换曲。
- 默认音量很低并做 6 秒淡入；`M` 键与右下角声音按钮挂起 AudioContext（真正静音，不是压增益）。
- 页面切到后台或窗口失焦时自动挂起，回到前台恢复（若此前已静音则不自动恢复声音）。
