# 指尖绽放 · 甬上四季

一幅会跟着你的手生长的四季画卷。山茶（春）、游鱼（夏）、桂（秋）、梅（冬）在画面中央次第绽放，配一段古风背景音乐。

---

## 一、怎么启动

> ⚠️ **不要直接双击 `index.html`**。摄像头在 `file://` 下会被浏览器拦截，必须通过本地服务访问。

### 方式一（推荐）：双击「启动.command」

1. 在项目文件夹里找到 **`启动.command`**，双击它。
2. 会弹出一个终端窗口，自动启动服务并用默认浏览器打开页面。
3. 页面加载后，点击中间的 **「点 击 进 入」** 按钮 → 浏览器弹窗请求摄像头时点 **「允许」**。
4. **用完关闭那个终端窗口即可停止服务。**

> **macOS 首次双击可能被拦截**：提示「无法打开，因为无法验证开发者」时，右键点击 `启动.command` → 选「打开」→ 在弹窗里再点「打开」即可。之后再双击就不会再拦了。

### 方式二（备选）：命令行

打开终端，执行：

```bash
cd 项目所在目录
python3 -m http.server 8000
```

然后浏览器打开 **http://localhost:8000**。终端窗口别关，关了服务就停了。

如果提示 `Address already in use`，说明 8000 端口被占了，换一个数字就行：

```bash
python3 -m http.server 8001
```

然后访问 `http://localhost:8001`。

## 二、怎么玩

| 操作 | 效果 |
| --- | --- |
| **右手张开 / 握拳** | 控制花朵绽开或合拢（张得越开，花开得越大） |
| **左手向外一挥** | 切换到下一个季节的花（春→夏→秋→冬→春） |
| 右下角小窗 | 摄像头回看，方便你把手放进画面；小窗可拖动 |
| 小窗底部「左手 / 右手」标签 | 检测到对应手时亮起朱砂红，没检测到时变暗 |

### 键盘降级（摄像头用不了时）

| 按键 | 作用 |
| --- | --- |
| `空格` | 花朵绽开 |
| `←` / `→` | 切换上一个 / 下一个季节 |

## 三、按键一览

| 按键 | 功能 |
| --- | --- |
| `D` | 演示模式（隐藏所有 UI 元素，只留花和字，适合录屏） |
| `Esc` | 退出演示模式 |
| `M` | 静音 / 恢复声音（也可点右下角喇叭按钮） |

> 演示模式下，摄像头小窗、左右手标签、提示文字都会隐藏，画面只保留花与题字，干净适合录屏。

## 四、常见问题

**Q：点击「进入」后没有弹出摄像头授权窗口？**
A：检查浏览器地址栏左侧有没有摄像头图标被划掉，点它改成「允许」。或者换 Chrome / Edge 浏览器。

**Q：摄像头画面里没有人，花不动？**
A：把脸和手都放进画面，光线别太暗。右手要完全张开再握拳，多试几次。

**Q：光线太暗识别不出来？**
A：开灯，让手和背景有明显亮度差。手离摄像头 30–60 厘米效果最好。

**Q：花不动 / 手势没反应？**
A：先看右下角小窗有没有画面。如果画面是黑的，说明摄像头没拿到权限，刷新页面重新授权。如果小窗有画面但花不动，试试把手放近一点、张开幅度大一点。

**Q：没有声音？**
A：必须先点「点 击 进 入」按钮才会解锁声音（浏览器策略）。按 `M` 键或右下角喇叭按钮可以切换静音。

## 五、目录说明

```
flowers/
├── index.html / style.css / app.js   网页本体（运行必需）
├── assets/                           运行要用的图片、帧序列、背景音乐
│   ├── seq/                          原始帧序列（不直接用）
│   ├── seq_norm/                     归一化后的帧序列（页面实际加载）
│   └── music/                        背景音乐 + 授权说明
├── vendor/                           MediaPipe 手势识别库与模型（运行必需）
├── 启动.command                       双击启动本地服务（推荐）
├── tools/                            生成与检查脚本（抠图、帧归一化、自检页）
├── docs/                             设计文档
├── _archive/                         旧版本、实验截图、参考视频等归档
└── class-kit/                        教学课件（另一个任务维护）
```

平时只需要管根目录的几个文件和 `启动.command`，其它文件夹不用动。
